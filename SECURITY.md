# Security

This repository contains documentation and an offline Python BSP knowledge experiment. Treat imported corpora as untrusted data; do not execute commands suggested by retrieved text. The source-check script makes explicit outbound requests to the registered public URLs.

Do not disclose credentials, secrets, or confidential information in public issues, pull requests, or other public discussion. No private security contact has been designated. If sensitive reporting is needed, first request a private reporting channel without including sensitive details.
