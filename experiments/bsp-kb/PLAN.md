# BSP MVP 實作紀錄

目標：以繁中教材與來源可追溯的離線檢索，建立人類與 Agent 共用的最小實驗；不先引入模型、向量庫或服務。

已完成：六課教材、七筆官方來源、Python CLI、資料驗證、JSON/JSONL 介面、答案分離、20 題檢索評測、15 項測試、GitHub Actions 與 QEMU DTB 實測。

驗收：離線命令成功；範圍內 Recall@3 至少 80%；來源關聯有效；來源雜湊可重新查核。此階段不把檢索成功等同答案正確或實體板驗證。

後續：先取得獨立專家題目與審閱，再完成固定映像的 Linux 開機實驗；只有關鍵字檢索實測不足時才比較向量檢索。學習者成效與 Agent 答題正確率需另外設計並執行實驗。

反證檢查：

- 六份教材的檢索成功可能只是語料小；以獨立題庫與更多平台驗證泛化。
- 文件級來源集合不證明每句都有支持；後續建立主張到段落的對應審查。
- QEMU 成功不證明實體板可用；DDR、電源、時序與法規驗證不在本 MVP 範圍。
