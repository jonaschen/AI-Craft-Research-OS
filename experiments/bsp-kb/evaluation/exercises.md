# 人類練習與答案（不匯出給 Agent）

前測與後測使用相同概念但調換題序；每題 0–2 分：缺答 0、部分正確 1、完整並能指出來源 2。以下是作者制定的評分規則，尚未收集學習者資料。

1. BSP 各層如何分工？答案：啟動準備、硬體描述、驅動與使用者空間分開追查；見 bsp。
2. ARM64 x0 與 DTB 對齊要求？答案：x0 指向 DTB 實體位址、8-byte 對齊；見 boot。
3. U-Boot 提示符是否證明 Linux 啟動？答案：否，須另觀察核心及使用者空間；見 uboot。
4. compatible 是否能替代驅動？答案：否，硬體描述仍需驅動支援；見 devicetree。
5. match 成功是否等於 probe 成功？答案：否，probe 還需確認及初始化；見 drivers。
6. Buildroot 映像在哪裡？答案：output/images；應記錄版本、設定及映像雜湊；見 buildroot。
